# XP IBRA — قائمة تعريبات الألعاب

هذا المستودع فيه **قائمة روابط لتعريبات الألعاب العربية**، ويقراها لانشر **XP IBRA** عشان يعرض لكل لعبة التعريبات المتوفرة لها (نافذة «🌐 تعريبات متوفرة…»).

الملف اللي يقراه اللانشر:

```
https://raw.githubusercontent.com/ibrahim828282/XP-IBRA-Arabic/main/catalog/arabic.json
```

اللانشر يحفظ نسخة منه 6 ساعات، فأي تعديل هنا يوصل للناس خلال 6 ساعات تقريباً.

## وش فيه بالضبط

| الملف | وش هو |
|---|---|
| `catalog/arabic.json` | القائمة نفسها: الألعاب، ولكل لعبة التعريبات المتوفرة لها |
| `catalog/arabic.schema.json` | شكل الملف وشرح كل حقل (JSON Schema) |
| `CONTRIBUTING.md` | خطوات إضافة تعريب وشرح الحقول |
| `.github/` | نماذج الاقتراح، والفحص التلقائي للقائمة والروابط |

## مهم: الحقوق

- القائمة فيها **روابط ومعلومات بس**. ما فيه أي ملف تعريب في هذا المستودع.
- **كل تعريب حقوقه لفريقه أو المعرّب نفسه**، والتحميل يكون **من مواقعهم** هم.
- رخصة هذا المستودع (CC BY 4.0) تخص **بيانات القائمة نفسها** فقط، مو التعريبات. كل تعريب له رخصة فريقه وشروطه.

## كيف تقترح تعريب

أي طريقة من هذي:

1. **نموذج في GitHub** (الأسهل): [اقتراح تعريب](https://github.com/ibrahim828282/XP-IBRA-Arabic/issues/new?template=add-translation.yml)
2. **Pull Request**: عدّل `catalog/arabic.json` وارسل PR (الخطوات في [CONTRIBUTING.md](CONTRIBUTING.md)).
3. **الديسكورد**: https://discord.gg/F2VbkNMNPz

ولقيت رابط ما يشتغل؟ [بلّغ عنه هنا](https://github.com/ibrahim828282/XP-IBRA-Arabic/issues/new?template=broken-link.yml).

## شروط القبول

يُقبل الاقتراح لو فيه:

- **رابط من الصفحة الرسمية** للفريق أو المعرّب (مو رابط منقول من موقع ثاني).
- **اسم الفريق** أو المعرّب.
- **نوع التعريب** (ملفات pak، ملفات تُنسخ، مثبّت، أو ورشة ستيم).
- **نسخة اللعبة** اللي يدعمها التعريب، لو معروفة.

**ممنوع:**

- روابط كراك، أو نسخ مكركة، أو ملفات تفك حماية الألعاب.
- رفع ملفات تعريب ناس **بدون إذنهم** (هنا أو في أي مكان).
- تعريبات مخترعة أو ما لها صفحة حقيقية.

## الفحص التلقائي

- مع كل Push وPull Request: يتأكد إن `arabic.json` صالح حسب الـ schema، وما فيه ألعاب أو تعريبات مكررة، وكل الروابط `https`.
- مرة بالأسبوع: يفتح كل رابط في القائمة، ولو فيه رابط خربان يفتح Issue لحاله.
